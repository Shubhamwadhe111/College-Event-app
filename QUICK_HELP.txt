CURRENT TASK: Import Database Schema to Aiven
--------------------------------------------------------------------------------

STEP 1: Test Connection
------------------------
Command:  node test-aiven-connection.js

You need:
  - Aiven Host (e.g., nexus-mysql-xxx.aivencloud.com)
  - Aiven Port (e.g., 27589)
  - Aiven User (usually: avnadmin)
  - Aiven Password
  - Database Name (usually: defaultdb)

Expected: "Connection successful!" + "0 tables found"


STEP 2: Import Schema
----------------------
Command:  node import-schema-node.js

Enter same details as Step 1
Wait 30-60 seconds

Expected: "Schema imported successfully!" + "17 tables created"


STEP 3: Verify Import
----------------------
Command:  node test-aiven-connection.js

Expected: "Connection successful!" + "17 tables found"


STEP 4: Update Backend Config
------------------------------
File: server/.env

Update these lines:
  DB_HOST=your-aiven-host.aivencloud.com
  DB_PORT=27589
  DB_USER=avnadmin
  DB_PASSWORD=your-password
  DB_NAME=defaultdb


STEP 5: Test Backend
--------------------
Command:  cd server
          node test-db.js

Expected: "Database connection successful!"


STEP 6: Deploy to Render
-------------------------
See: DEPLOY_BACKEND_GUIDE.md


================================================================================
TROUBLESHOOTING
================================================================================

Problem: Password prompt doesn't show anything
Solution: That's normal! Just type and press Enter

Problem: Can't connect to database
Solution: 
  - Check Aiven service is running (green status)
  - Copy-paste password from Aiven (don't type)
  - Verify all connection details

Problem: DELIMITER errors
Solution: Ignore them - they're harmless

Problem: Script hangs
Solution: Press Ctrl+C and try again
