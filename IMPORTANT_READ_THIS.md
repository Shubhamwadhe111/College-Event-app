**Chrome:**
1. Press `Ctrl + Shift + Delete` (or `Cmd + Shift + Delete` on Mac)

3. Time range: "Last hour" or "Last 24 hours"
4. Click "Clear data"
5. Reload the website

1. Press `Ctrl + Shift + Delete`
2. Select "Cache"

4. Reload the website

**Edge:**
1. Press `Ctrl + Shift + Delete`

3. Click "Clear now"
4. Reload the website

## 🤔 Why Does This Happen?

**Browser Cache:**
- Browsers save old versions of websites to load faster
- When we deploy new changes, your browser still shows the old version
- Clearing cache forces browser to download the new version

**GitHub Pages CDN:**
- GitHub uses a Content Delivery Network (CDN)
- Changes can take 5-10 minutes to reach all servers worldwide
- If you just saw the deployment, wait a few minutes
